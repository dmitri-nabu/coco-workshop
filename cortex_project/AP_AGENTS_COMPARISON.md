# AP Agents: Differences and Use Cases

Both agents are in `COCO_WORKSHOP.PIPELINE_LAB`. They use the same semantic view (`SV_AP_ANALYTICS` over
`SILVER_AP_INVOICES`), the same warehouse (`COMPUTE_WH`) and the same data guardrails. They differ in **how they answer**.

| | `AP_INVOICES_AGENT` | `AP_ANALYTICS_ASSISTANT` |
|---|---|---|
| Spec file | `AP_INVOICES_AGENT.agent.yaml` | `AP_ANALYTICS_ASSISTANT.agent.yaml` |
| Tool | `ap_invoice_analytics` (Cortex Analyst) | `ap_analytics` (Cortex Analyst) |
| Audience | Business users: AP leads, controllers, finance leadership | Analysts, data engineers, reviewers who need to check answers |
| Response shape | Free-form answer plus a short scope note | Always 3 sections: **Answer**, **SQL used**, **Assumptions (grain & filters)** |
| SQL visibility | Hidden (trace only) | Shown verbatim as generated by Cortex Analyst |
| Ambiguous questions | Picks a sensible default and states it | Asks **one** clarifying question (with a default) before querying |
| Currency ranking | Sorts raw amounts across currencies (noted, not fixed) | Ranks within each currency in the answer text |
| Best for | Fast answers, dashboards-style Q&A, Snowflake Intelligence end users | Audit, validation, debugging the semantic view, teaching SQL patterns |

## Shared guardrails (both agents)
- Only use SV_AP_ANALYTICS. Never invent vendors, amounts, dates or fields
- Never add up or convert amounts across currencies. FX conversion happens in Gold
- "Unpaid / outstanding / open" means approval status PENDING (the data has no payment status)
- "Business unit" means the source ERP (SAP, ORACLE, BAAN, WORKDAY)
- Relative periods are anchored on the latest INVOICE_DATE (the data is a snapshot, 2025-01-10 to 2025-06-01)
- Report missing data (payment dates, FX, unified chart of accounts, vendor master, entity) as unavailable. Read-only. Decline non-AP questions

## When to use which
**Use `AP_INVOICES_AGENT` when**
- The user wants the number, not the method: "How much is pending approval for Baan?"
- It's exposed in Snowflake Intelligence to non-technical finance users
- Short, conversational answers matter more than traceability

**Use `AP_ANALYTICS_ASSISTANT` when**
- The answer must be reviewable or reproducible: month-end checks, reconciliations, sign-off
- You're validating SV_AP_ANALYTICS changes (inspect the generated SQL and its grain)
- Questions are open-ended ("show me vendor trends"), so a clarifying question avoids a wrong default
- You're onboarding analysts who will later write the SQL themselves

## Observed behavior (2026-10-20 tests)
| Prompt | AP_INVOICES_AGENT | AP_ANALYTICS_ASSISTANT |
|---|---|---|
| "Top 10 vendors by unpaid invoice amount" | 9 vendors, pending = unpaid stated, ranked across currencies | 3 sections; answer grouped by currency; SQL shown; grain and filters listed |
| "Total AP spend in USD across all business units" | Declined to combine; per-currency totals (972,150 USD / 370,051.25 EUR / 105,200 GBP) | Not tested |
| "Show me vendor trends" | Not tested | Asked: spend or count, and which grain (default: spend by month) |
| "Which invoices have been paid late this year?" | Not tested | Said no payment data exists; offered past-due pending invoices instead |
